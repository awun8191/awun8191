## Flagships

### [Vigil](https://github.com/awun8191/vigil)
Self-hostable proactive AI assistant. Postgres-backed agent runtime with approval-gated sandboxed execution, pgvector memory, and a React client. 612 tests. 159+ commits. Runs with Docker Compose.

**Stack:** Python, FastAPI, PostgreSQL 16 + pgvector, React, TypeScript, Docker, MCP

---

### [Storefront Platform](https://github.com/awun8191/storefront-platform)
Reference implementation of a single-store commerce backend. FastAPI API with Cloudflare D1 data worker, proxy workers, and SQL migrations. ERD, payment flow docs, and a one-command demo.

**Stack:** FastAPI, Python 3.14, Cloudflare D1, R2, Workers, Firebase Auth, Paystack

---

### [JEV Resume Analyzer](https://github.com/awun8191/jev-resume-analyzer)
Resume and CV analysis tool. Scores content from 0 to 100, checks layout quality, and measures job alignment. Uses a structured rubric with prompt logic and a TypeSafe Jev scoring engine.

**Stack:** FastAPI, React, TypeScript, TypeSafe Jev
